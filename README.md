# Warmtewijs

Landing page for Warmtewijs, an independent AI energy advisor for Dutch homes. Built with Next.js (App Router) and TypeScript.

Live: https://warmtewijs.vercel.app

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run lint` — run ESLint

## Deployment

Hosted on Vercel. Every push to `main` deploys to production.
